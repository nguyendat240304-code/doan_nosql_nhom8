Import / Export Dữ liệu theo Lớp học phần

Export Hồ sơ Sinh viên

Xuất danh sách sinh viên và bảng điểm theo Lớp học phần ra file JSON.

Chọn một lớp học phần cụ thể để trích xuất danh sách sinh viên của lớp đó.
File JSON xuất ra có thể dùng để lưu trữ hoặc nạp lại vào hệ thống.
Nhập dữ liệu Sinh viên

Tải dữ liệu từ tệp JSON. Hệ thống tự động hợp nhất bảng điểm, không làm mất các môn đã có.

Nếu chọn lớp cụ thể, sinh viên trong file sẽ được tự động xếp vào lớp học phần này.
Dữ liệu trùng MSSV sẽ được cập nhật/bổ sung, không bị mất môn học khác.
Cấu trúc file JSON mẫu (Dùng khi Thuyết trình & Báo cáo)
